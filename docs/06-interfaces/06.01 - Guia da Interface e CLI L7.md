# Guia da Interface de Exploração (Ciclo 08)
## Camada L7 (Presentation) e os 3 Níveis de Abstração

---

### 1. Arquitetura da Camada L7

A camada **L7 (User Interface / Presentation)** da *Scientific Systems Exploration Platform* materializa os três modos de interação concebidos para o pesquisador, garantindo estrita observância à regra de dependência:

$$\text{CLI / Presentation (L7)} \longrightarrow \text{Exploration Service (L6)} \longrightarrow \text{Scientific Computing (L5)} \longrightarrow \text{Domain / Evidence (L4/L3)}$$

A interface **nunca** acessa dados científicos ou motores de cálculo diretamente; todo o fluxo transita por ViewModels imutáveis intermediados pela camada de aplicação.

---

### 2. O Epistemic Firewall na Interface

Toda informação apresentada pela interface carrega explicitamente:
1. **Tier de Dados:** `[RAW]`, `[DERIVED]` ou `[GENERATED]`.
2. **Status Epistêmico:** `[OBSERVED]`, `[PREDICTED]`, `[VALIDATED]`, `[CONTRADICTED]`.
3. **Alerta de Fronteira:** Se o usuário submeter o sistema a parâmetros que extrapolem o envelope experimental validado (por exemplo, forçar $F_{\text{load}} > 0 \text{ pN}$ no modelo calibrado para carga nula), a interface exibe um aviso destacado notificando a refutação empírica da condição.

---

### 3. Os Três Modos de Visualização

#### Modo 1: Modo Usuário (Operacional / Simulação Direta)
Focado no comportamento funcional macroscópico. Permite simular o avanço do motor sob concentrações arbitrárias de ATP e forças de carga.

* **Comando:**
  ```bash
  .venv/bin/python presentation/cli/main.py user --atp 1000 --load 0
  ```
* **Exemplo de Saída sob Condição Validada:**

---

#### Modo 2: Modo Engenheiro (Componentes e Parâmetros)
Abre os blocos operacionais do sistema: exibe as entidades físicas e biológicas catalogadas, seus códigos externos (UniProt/PDB), parâmetros calibrados com margens de sensibilidade e limites do envelope de operação.

* **Comando:**
  ```bash
  .venv/bin/python presentation/cli/main.py engineer
  ```
* **Conteúdo Apresentado:**
  * Entidades: `[PROTEIN] KIF5B (UniProt:P33176, PDB:1BG2)` e `[FILAMENT] Microtubule (PDB:1JFF)`.
  * Parâmetros calibrados: $k_{cat} = 103.92 \text{ s}^{-1}$, $K_m = 94.63 \ \mu\text{M}$, $d_{\text{step}} = 8.2 \text{ nm}$.
  * Limites de sensibilidade e contagem de evidências empíricas de suporte ($10$ registros).

---

#### Modo 3: Modo Científico (Caixa-Preta Aberta e Conflitos)
Expõe as entranhas teóricas e a auditabilidade epistêmica: lista todas as premissas simplificadoras declaradas pelo modelo, a cadeia de proveniência ponta a ponta e a matriz de afirmações ativas e contradições.

* **Comando:**
  ```bash
  .venv/bin/python presentation/cli/main.py scientist
  ```
* **Conteúdo Apresentado:**
  * Premissas Simplificadoras do modelo `MOD-KIF5B-MINIMAL-MM` (INV-MODEL-001).
  * Trilha de Proveniência: *Source $\to$ Experiment $\to$ Observation $\to$ Evidence $\to$ Claim $\to$ Model $\to$ Simulation $\to$ Prediction*.
  * Afirmações Ativas:
    * `CLM-REPRO-KIF5B-UNLOADED-001` com status `[DERIVED | VALIDATED]`.
    * `CLM-FALSIF-KIF5B-LOAD-001` com status `[DERIVED | CONTRADICTED]`.
  * Auditoria de Conflitos: Registro `CONF-KIF5B-LOAD-001` detalhando a falha mecanoquímica de $\approx 50\sigma$ sob carga contrária.

### 5. Central Unificada de Administração (`manage.py` e `./cell-ctl`)

Para dispensar a digitação de caminhos extensos de interpretador e orquestrar o ciclo completo de vida do projeto, foi criada uma central de controle em camadas:

#### Execução via Wrapper Direto (`./cell-ctl`)
```bash
./cell-ctl status            # Exibe o status consolidado do grafo epistêmico
./cell-ctl user              # Executa simulação em regime validado (1000 µM ATP, carga nula)
./cell-ctl user --load 4.0   # Executa simulação sob carga (dispara alerta do Epistemic Firewall)
./cell-ctl engineer          # Modo Engenheiro (componentes, entidades UniProt/PDB e parâmetros)
./cell-ctl scientist         # Modo Científico (proveniência e auditoria formal de conflitos)
./cell-ctl design            # Proposta de Desenho Experimental Discriminatório (Ciclo 09)
./cell-ctl reproduce         # Executa o pipeline de reprodução do Dataset A
./cell-ctl falsify           # Executa o pipeline de falsificação do Dataset B
./cell-ctl test              # Executa a suíte de 29 testes do pytest
./cell-ctl verify            # Auditoria formal completa de dados, schemas e invariantes
./cell-ctl demo              # Bateria completa e pedagógica de demonstração (L1 a L7)
```

#### Execução via Makefile
```bash
make status
make user
make user-falsified
make engineer
make scientist
make design
make test
make verify
make demo
```
